① 配色令牌速查

点击任意色块即可复制其 CSS 变量用法。所有颜色以 RGB 三元组存于 :root，配合 alpha 使用（如 rgb(var(--cyan) / 0.6) 等价于旧 rgba(0,191,255,0.6)）。

② 核心组件规范（可直接粘贴）

以下片段均来自线上 common.css，复制即用，确保零漂移还原。

直角按钮 / 输入框（全局规范）

.filter-btn, .cal-nav, .cal-cell, button, input {
  border-radius:0;            /* 全站按钮/控件一律直角，禁用圆角 */
}
.filter-btn {
  border:1px solid rgb(var(--cyan) / 0.6);
  box-shadow:0 0 12px rgba(0,191,255,0.4), inset 0 0 8px rgba(0,191,255,0.15);
  color:rgb(var(--cyan)); background:rgba(0,191,255,0.06);
}

面板 / 弹窗发光描边

.panel, .modal-dialog {
  border:1px solid rgb(var(--cyan) / 0.55);

字段驱动弹窗（数据来自触发元素 data-cols）

/* 触发：data-modal="ranking" data-cols="rank:排名|name:公司|sub:同比|val:资产价值" */
.modal-table th { font-size:16px; }      /* 表头最小 16px */
.modal-table .f-val { font-size:19px; font-weight:700; color:rgb(var(--cyan)); }  /* 数字列加粗放大 */
/* 进场：竖线 → 向两边展开；出场：向中间收拢 */
.modal-overlay.open .modal-dialog { animation:modalIn .5s cubic-bezier(.22,.61,.36,1) forwards; }
